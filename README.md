# My Sales App

My Sales App is a modern sales and billing web application built for small businesses to manage customers, invoices, payments, and financial records from a single dashboard. The app is designed to simplify daily sales operations, track outstanding balances, and provide a clear overview of business performance.

## Overview

This project is a lightweight, browser-based billing and sales management tool. It helps businesses:
- manage customer records
- create and track invoices
- record payments and customer balances
- monitor sales activity
- generate payment/invoice reports
- maintain local backups and restore previous data

The app is implemented as a static HTML application with embedded JavaScript and CSS, making it easy to run without a complex frontend framework or build step.

## Features

- Dashboard with sales and business summary
- Customer management
- Invoice creation and tracking
- Payment recording
- Ledger and customer balance tracking
- Product/item catalog
- Reports and financial summaries
- Local backup and restore support
- Offline-friendly behavior
- Optional Supabase integration for cloud sync and authentication
